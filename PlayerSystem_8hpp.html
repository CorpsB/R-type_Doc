Detailed Description

Header for PlayerSystem — ECS system handling player movement, firing, and score updates.

Author
Jason KOENIG
Date
29/06/2025

Declares PlayerSystem, a concrete ECS system responsible for applying player-related logic. It interprets player input, moves entities accordingly, triggers firing behavior, and adjusts player scores.

Responsibilities:

  • Move player entities according to input direction and speed.
  • Manage firing state through frequency_attr_t components.
  • Update score attributes safely within valid ranges.

The system processes all entities tracked in _filtered_entities (assigned by SystemManager) and interacts with the Coordinator to access required components.
