Detailed Description

Component storage implementation for the ECS.

Since
0.1
See also
IComponentArray.hpp, ComponentManager.hpp

ComponentArray is a contiguous storage for components of type T mapped to entity IDs. It provides insertion, removal, lookup and lifecycle integration for component instances. The implementation uses dense storage with index indirection tables for O(1) insert/remove.
