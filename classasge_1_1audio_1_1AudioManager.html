Detailed Description

High-level audio control system for the ASGE engine.

The AudioManager acts as a bridge between the engine logic (e.g., gameplay code) and the selected backend AudioDriver. It provides a simple, consistent API for sound playback, caching, and volume control.

It does not perform decoding itself — all low-level work is delegated to the driver. However, it manages:

  • caching and reuse of loaded sounds,
  • on-demand loading from file or memory,
  • volume scaling relative to the master volume,
  • synchronization between threads using a mutex.

This class is instantiated by the engine core and accessed through the global service registry (asge::Services).
