Detailed Description

Central reliable networking service (protocol, sessions, retransmit).

Since
0.1

Implements the high-level INetwork facade with a reliability layer (stop-and-wait on channel 0), ACK-only signaling, retransmission with adaptive RTO, and per-peer session tracking. Uses a pluggable NetworkChannel for the transport (e.g., UDP, loopback).

◆ asge::network::NetHeader

struct asge::network::NetHeader

On-wire header (12 bytes) prepended before each payload.

Binary layout (little-endian):

  • seq (uint32) : sender sequence (reliable channel only).
  • ack (uint32) : last received/accepted sequence (ACK-only possible).
  • flags (uint8) : bitfield (FLAG_ACK_ONLY, FLAG_RELIABLE, ...).
  • channel (uint8) : 0 = reliable; >0 = best-effort channels.
  • reserved(uint16) : reserved for future extensions / alignment.

struct asge::network::NetworkManager::InFlight

Tracks an outstanding reliable packet awaiting ACK.

  • packet : full serialized bytes (header + payload).
  • lastSend : timestamp of last transmission attempt.
  • rto : current retransmission timeout.
  • seq : sequence number used in the header.
  • channel : logical channel (usually 0 for reliable).
  • addr:port : destination endpoint.
