Detailed Description

Fundamental types used by the scripting subsystem.

Contains lightweight data structures used to represent parsed script/templates, queued actions created by the script manager and a generic JSON-backed script value alias used by runtimes and host APIs.

struct asge::script::PositionTrigger

A single position-trigger entry (as represented in JSON).

PositionTrigger stores the raw condition (kept as JSON for later evaluation), the list of action strings to execute when the condition matches, a flag to run the trigger only once, and an optional throttle in milliseconds to limit re-firing.

struct asge::script::QueuedAction

Queued action produced by ScriptManager when hooks run or entity created.

ScriptManager enqueues these actions for later processing by the engine's script execution pipeline. An entity_id of 0 indicates the action is not bound to a concrete entity (template-level or spawn request).
