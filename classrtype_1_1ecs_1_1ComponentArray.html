Detailed Description

template<typename T>
class rtype::ecs::ComponentArray< T >

Dense component container mapping entity IDs to components.

Template Parameters
TComponent type stored in this container.

ComponentArray stores components in a compact vector and maintains two indirection vectors to map between component slot indices and their owning entity IDs:

  • _component_to_owner: index -> entity_id
  • _owner_to_component: entity_id -> index

This design enables O(1) insertion, removal (by swap-with-last) and lookup.
