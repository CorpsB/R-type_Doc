35 * @class Protocol
36 * @brief Singleton core class responsible for low-level UDP messaging.
37 *
38 * @details
39 * Protocol manages a single UDP socket, sequence numbering, ack bookkeeping,
40 * and event delivery. The class is provided as a singleton to avoid global
41 * instance management in application code.

123

134
135 /**
136 * @brief Get an approximate packet loss rate between 0.0 and 1.0.
137 * @return estimated packet loss rate

139 double get_packet_loss_rate() const noexcept;
140
141 /**
142 * @brief Store a "preferred" remote endpoint for convenience operations.
143 * @param ep UDP endpoint (address + port) to store.
144 *
145 * @details
146 * The Protocol core keeps an optional stored endpoint that higher-level
147 * facades may use as a default destination for convenience functions.
148 * Calling storeEndpoint stores a copy of @p ep into an internal optional.
149 */
150 void storeEndpoint(const udp::endpoint &ep);
151
152 /**

210 /**
211 * @brief Post an asynchronous send for a prepared packet_t.
212 * @param packet Packet to send (header in host byte order, packet.remote must be set).
213 * @return async_send_to post result.
214 *
215 * @details
216 * This function builds the wire buffer (serialize_packet_ack) and posts an
217 * async_send_to on the internal UDP socket. It does not alter reliable-send
218 * bookkeeping (i.e. _pending_sends must be managed by the caller/other functions).

220 bool send_buffered_packet(const packet_t &packet) noexcept;

227 * @details
228 * Called when a reliable packet (identified by @p seq) has exhausted retransmit

230 */
231 void emit_transmit_failed(uint32_t seq, const packet_t &orig_packet);
232
233 /**

239 * the provided packet into the event payload. It then notifies any waiter on _event_cv.
