Detailed Description

Raylib-only driver: lifecycle + high-level drawing.

Cycle de vie typique :

driver.init(w, h, "title");
while (running) {
driver.beginFrame();
driver.clear(0,0,0,1);
draw calls...
driver.present();
}
driver.shutdown();
Note
Les ressources GPU (textures) créées par createTextureFromPixels() doivent être libérées via destroyTexture().
