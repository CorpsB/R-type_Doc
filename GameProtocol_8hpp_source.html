8/**
9 * @file GameProtocol.hpp
10 * @brief High-level game protocol facade (header only).
11 * @since 0.1
12 * @ingroup protocol::game
13 * @see Core/Protocol.hpp, GameProtocolTypes.hpp
14 *
15 * @details
16 * GameProtocol is a small singleton facade built on the low-level protocol::Protocol.
17 * It offers convenience functions to send the game-level messages declared in
18 * GameProtocolTypes.hpp and a polling API (is_event / wait_event) returning
19 * game-level events. The implementation (cpp) is responsible for packing
20 * payload structures into raw bytes and for translating core events into
21 * game_event_t instances.
22 */

35/**
36 * @namespace GameProtocol
37 * @brief Facade exposing game-level send/poll APIs.
38 *
39 * @details
40 * GameProtocol sits on top of the low-level Protocol singleton and provides:
41 * - convenience sending functions for game messages (create/move/destroy, input)
42 * - raw send helper that accepts an explicit reliability flag
43 * - a polling API that yields high-level game_event_t objects
44 * - lightweight wrappers to control the underlying IO thread and pending queue polling
45 *
46 * Implementation note:
47 * - This header only contains signatures and documentation. The implementation
48 * file should convert game payload structures into raw byte buffers and call
49 * protocol::Protocol::instance().send_packet(...).
50 */
