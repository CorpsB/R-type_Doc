Detailed Description

Facade exposing game-level send/poll APIs.

GameProtocol sits on top of the low-level Protocol singleton and provides:

  • convenience sending functions for game messages (create/move/destroy, input)
  • raw send helper that accepts an explicit reliability flag
  • a polling API that yields high-level game_event_t objects
  • lightweight wrappers to control the underlying IO thread and pending queue polling

Implementation note:

  • This header only contains signatures and documentation. The implementation file should convert game payload structures into raw byte buffers and call protocol::Protocol::instance().send_packet(...).
