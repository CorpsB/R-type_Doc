Detailed Description

Concrete implementation of the scripting subsystem manager.

Implements IScript and coordinates a ScriptRuntime instance (if provided) to parse templates, merge inheritance and produce queued actions for the engine to execute. The manager relies on provided Services for storage access and logging.
