Detailed Description

Represents a managed instance of a loaded plugin.

Each PluginHandle is associated with a unique identifier (plugin ID), the path of the loaded shared library, and a shared pointer to the IPlugin implementation. It exposes basic accessors and an unload() method to safely release the plugin’s resources.
