Detailed Description

Global configuration macros for the ECS (component/entity limits).

Since
0.1
See also
ComponentManager.hpp, EntityManager.hpp

This header defines compile-time limits used by the ECS implementation:

  • MAX_COMPONENTS: maximum number of distinct component types supported.
  • MAX_ENTITIES: maximum number of simultaneously allocatable entities.
Warning
Changing these values impacts memory usage and correctness of internal fixed-size containers. Rebuild the project after modifying them.

Pack two 32-bit signed cell coordinates into a single 64-bit unsigned key.

Parameters
xCell x coordinate (int).
yCell y coordinate (int).
Returns
uint64_t Packed key where high 32 bits are the (uint32_t) x and low 32 bits are (uint32_t) y.

The function casts coordinates to uint32_t and packs them as (uint64_t(x) << 32) | uint32_t(y). This representation preserves uniqueness for all 32-bit coordinate pairs and is convenient for use as an unordered_map key. The function is noexcept.
