Detailed Description

Core transport primitives and low-level protocol types.

The protocol namespace contains the foundational types and constants used by the UDP transport core: wire packet header layout (packet_header_t), runtime packet wrapper (packet_t), reliability flags (flag_t), event payloads and diagnostic helpers. It also declares small utility containers used by the core (pending send state, per-peer receive state) and constants that control retransmit behaviour and maximum packet size.

All multi-byte fields on the wire are encoded in network byte order (big endian). Implementations that construct or parse packet headers MUST convert between host and network byte order using the provided helpers (e.g. protocol::utils::to_network_u32 / protocol::utils::from_network_u32).

◆ protocol::core_event_t

struct protocol::core_event_t

Core protocol event delivered by the low-level UDP transport.

The Protocol core produces discrete events that the upper layers consume. Each core_event_t contains:

  • type: an event_type_t enumerator describing the kind of event (PACKET_RECEIVED, CONNECTION_ESTABLISHED, CONNECTION_LOST, TRANSMIT_FAILED).
  • payload: a variant carrying the event data:
    • std::monostate for NONE,
    • packet_t for PACKET_RECEIVED (parsed header + payload + remote endpoint),
    • transmit_failed_t for TRANSMIT_FAILED (reliable send that exhausted retries).

Usage:

  • Consumers call Protocol::get_event() which fills a core_event_t.
  • For PACKET_RECEIVED events the payload holds the parsed packet that can be passed to higher-level protocol adapters (e.g. game facade).

◆ protocol::packet_header_t

struct protocol::packet_header_t

Fixed-size packet header at the beginning of each UDP datagram.

Wire layout (packed, network byte order):

  • uint16_t message_type
  • uint8_t flags
  • uint8_t reserved
  • uint32_t sequence
  • uint32_t ack
  • uint32_t ack_bits
  • uint16_t payload_length
Warning
Implementations MUST serialize fields to big-endian before sending.

◆ flag_t

enum class protocol::flag_t : uint8_t
strong

Reliability semantics encoded in packet header flags.

  • UNRELIABLE: do not retransmit (used for time-sensitive state).
  • RELIABLE_UNORDERED: retransmit until ack; order not enforced.
  • RELIABLE_ORDERED: retransmit and deliver in sequence (buffer until missing).
