Detailed Description

ECS system that updates sound playback for entities.

AudioSystem iterates over _filtered_entities (managed by SystemManager) and applies playback logic based on the audio_attr_t component:

  • play: starts playback if not already playing,
  • stop: stops current playback,
  • loop: restarts playback if the sound finished.

All sound resources are retrieved from the global ResourceManager singleton.

Complexity: O(n) per frame, where n is the number of audio-enabled entities.

void rtype::ecs::AudioSystem::update ( Coordinator &  coord)

Update all entities’ audio components for this frame.

Parameters
coordCoordinator reference to access components.

Iterates _filtered_entities and for each:

  • retrieves the audio_attr_t component,
  • gets the matching Sound resource,
  • applies play/stop/loop logic using Raylib functions.

Entities with invalid keys or missing sounds are silently skipped.
