37/**
38 * @brief Pack two 32-bit signed cell coordinates into a single 64-bit unsigned key.
39 *
40 * @param x Cell x coordinate (int).
41 * @param y Cell y coordinate (int).
42 * @return uint64_t Packed key where high 32 bits are the (uint32_t) x and low 32 bits are (uint32_t) y.
43 *
44 * @details
45 * The function casts coordinates to uint32_t and packs them as (uint64_t(x) << 32) | uint32_t(y).
46 * This representation preserves uniqueness for all 32-bit coordinate pairs and is convenient for
47 * use as an unordered_map key. The function is noexcept.
48 */
49uint64_t makeKey(int x, int y) noexcept;
