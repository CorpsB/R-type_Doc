Detailed Description

Per-peer state used by the reliable layer and session management.

Encapsulates:

  • Endpoint binding for this peer.
  • Send/receive sequencing for reliable messages (stop-and-wait in the current design).
  • Smoothed RTT in milliseconds (usable to derive RTO bounds).
  • Last receive tick (activity/keep-alive).
  • A basic congestion window hint cwnd (clamped by caller policy).

Typical usage:

  • Call bumpSendSeq when emitting a new reliable packet.
  • Call noteRecvSeq on valid in-order reception to advance the receive window and update activity time.
  • Feed new RTT samples via updateRtt when ACKs are observed.
