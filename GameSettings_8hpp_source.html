41/**
42 * @class GameSettings
43 * @brief Singleton managing runtime settings and UI scaling for the R-Type client.
44 *
45 * @details
46 * The GameSettings class centralizes the configuration and synchronization of rendering parameters,
47 * including screen dimensions, scale ratio, language tags, and global active state.
48 *
49 * It ensures a uniform display experience by maintaining proportional scaling relative
50 * to a predefined 16:9 reference resolution.
51 *
52 * This class also exposes helper methods to apply temporary settings (language, fullscreen, resolution)
53 * and synchronize internal states with the actual rendering window.
54 *
55 * ### Example:
56 * @code{.cpp}
57 * using namespace rtype::client;
58 * auto &settings = GameSettings::getInstance();
59 * settings.setScreenSize({1920, 1080});
60 * settings.setLangTag("EN");
61 *
62 * while (settings.getActive()) {
63 * settings.syncWithWindow();
64 * BeginDrawing();
65 * ClearBackground(BLACK);
66 * EndDrawing();
67 * }
68 * @endcode
69 *
70 * @see syncWithWindow, setScreenSize
71 */
