42/**
43 * @class GameSettings
44 * @brief Singleton managing global runtime and rendering configuration.
45 *
46 * @details
47 * The **GameSettings** class centralizes client-wide parameters such as window size,
48 * scaling, language, and runtime activity. It ensures a consistent rendering experience
49 * across resolutions by maintaining proportional scaling relative to a base 16:9 aspect ratio.
50 *
51 * Commonly used by UI elements and rendering subsystems to adapt their coordinates
52 * to the current viewport.
53 *
54 * ### Example usage:
55 * @code{.cpp}
56 * using namespace rtype::client;
57 *
58 * auto &settings = GameSettings::getInstance();
59 * settings.setScreenSize({1920, 1080});
60 * settings.setLangTag("FR");
61 *
62 * while (settings.getActive()) {
63 * settings.syncWithWindow();
64 * BeginDrawing();
65 * ClearBackground(RAYWHITE);
66 * // render stuff...
67 * EndDrawing();
68 * }
69 * @endcode
70 *
71 * @note Follows the singleton design pattern.
72 * @see syncWithWindow, setScreenSize
73 */
