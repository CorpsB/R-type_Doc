Detailed Description

Implementation of the OptionsMenuScene class for managing user configuration menus.

Since
1.0
See also
OptionsMenuScene.hpp, GameSettings, SceneManager

This file defines the logic for the options menu scene in the R-Type client. It provides a configurable menu interface that allows users to change resolution, display mode, and language at runtime. The menu also includes options to apply or cancel changes.

Responsibilities:

  • Manage menu option initialization and rendering.
  • Handle navigation and selection input.
  • Interface with GameSettings for configuration persistence.
Note
All UI elements are scaled dynamically based on GameSettings.
Warning
Input handling assumes keyboard navigation.
