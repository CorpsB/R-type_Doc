Detailed Description

template<typename T>
class asge::world::ComponentArray< T >

Dense component storage for a given component type.

Template Parameters
TComponent type stored in this array.

Index mapping:

  • _components[idx] → component instance
  • _component_to_owner[idx] → entity using that component
  • _owner_to_component[id] → index of component for that entity
