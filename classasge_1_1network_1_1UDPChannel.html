Detailed Description

Concrete NetworkChannel based on UDP sockets using Boost.Asio.

Provides low-level send/receive functions with optional batching and socket configuration. Designed for real-time game networking where minimal latency and fine-grained control are required.

Usage:

  • openServer(port) to bind for incoming packets.
  • openClient(address, port) to prepare for outbound traffic.
  • poll(callback) to process pending datagrams.
  • send(bytes) or sendTo(bytes, addr, port) for data transmission.
Note
Thread safety: internal mutex _mx guards socket state.
Warning
UDP is connectionless; packet delivery is not guaranteed.
