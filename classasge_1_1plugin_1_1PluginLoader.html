Detailed Description

Loads shared libraries and creates IPlugin instances.

Typical usage:

  • Call load() with a filesystem path to a shared library.
  • Use the returned plugin instance in higher-level systems.
  • On shutdown, call unloadAll() to release all native handles.

std::shared_ptr< IPlugin > asge::plugin::PluginLoader::load ( const std::string &  path)
virtual

Loads a shared library and instantiates an IPlugin.

Parameters
pathFilesystem path to the plugin library.
Returns
A std::shared_ptr<IPlugin> constructed from the library’s factory entry point (e.g., CreatePlugin).

This function:

  1. Opens the native library (platform-specific).
  2. Resolves the factory symbol (e.g., CreatePlugin).
  3. Constructs and returns the plugin instance.
  4. Stores the native handle internally for later release.
Exceptions
error::ErrorIf the path is empty, the library cannot be opened, the factory symbol cannot be resolved, or the factory returns a null instance.
