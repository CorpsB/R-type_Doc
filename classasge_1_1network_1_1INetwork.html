Detailed Description

Base interface for all networking implementations.

Defines the minimal set of methods needed by the engine to communicate over the network. Implementations can be:

  • Real transports (e.g. UDP, TCP, reliable layer).
  • Simulated or null (for headless or test runs).

Typical usage pattern:

std::unique_ptr<INetwork> net = std::make_unique<UDPNetwork>();
net->startServer(4200);
net->poll([](const std::vector<std::uint8_t>& data) { handlePacket(data); });
