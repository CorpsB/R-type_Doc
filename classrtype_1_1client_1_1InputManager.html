Detailed Description

Singleton managing user input and key bindings.

The InputManager centralizes keyboard event handling by associating string-based action names with specific key codes.

It provides per-frame queries for:

  • pressed() — true only on the frame the key is first pressed.
  • down() — true as long as the key is held.
  • released() — true only on the frame the key is released.

This design decouples input logic from specific hardware keys, allowing for configurable and readable game controls.
