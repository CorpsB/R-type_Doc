Detailed Description

Interface that all scenes must implement.

Defines the base contract for a scene object within the R-Type client. Every scene provides lifecycle hooks and two core methods:

  • update: handles logic and state progression.
  • draw: handles rendering of visual elements.

Lifecycle methods like onEnter and onExit allow controlled transitions managed by SceneManager.
