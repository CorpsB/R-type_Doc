Detailed Description

Concrete ITimer implementation using std::chrono.

SystemTimer provides a simple high-resolution system timer. It measures real elapsed time between frames or operations, and maintains an atomic tick counter.

Thread-safety:

  • Read operations are thread-safe.
  • Internal state updates (tick()) are protected by _mutex.

Logging:

  • Any unexpected condition (e.g. negative delta) can be logged via _debugger.
