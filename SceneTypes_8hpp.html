Detailed Description

Fundamental POD types and enums used by the scene subsystem.

This header declares lightweight, copyable types and enums used across the scene manager and scene implementations:

  • SceneId: numeric unique identifier for a pushed scene instance.
  • SceneParams: string-string parameter bag forwarded at scene creation.
  • SceneFlag: bitflags describing scene behaviour (Overlay, Modal, Persistent).
  • SceneHandle: a compact descriptor representing a pushed scene (id, type, flags, params).
  • SceneState: lifecycle states tracked by scenes.

These types are intentionally small and header-only so they can be used in headers across the engine without requiring heavy includes.

struct asge::scene::SceneHandle

Lightweight descriptor for a pushed scene instance.

SceneHandle represents metadata for a scene instance pushed onto the SceneManager stack. It is intentionally copyable and small so the manager can queue pending operations using it.

Members:

  • id: numeric id assigned by SceneManager (0 = invalid/unassigned).
  • type: textual type identifier used for diagnostics and factory lookups.
  • flags: SceneFlag bitset describing overlay/modal/persistence behaviour.
  • params: optional key/value parameters forwarded to scene init.
