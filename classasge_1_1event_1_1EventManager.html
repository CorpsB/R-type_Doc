Detailed Description

Thread-aware event bus implementation.

Responsibilities:

  • publish() dispatches immediately to current subscribers.
  • publishDeferred() enqueues the event for later dispatch by flush().
  • subscribe() returns a uint64_t id which is used to unsubscribe().

Thread-safety:

  • All public methods are safe to call concurrently.
  • Internal state (_subs, _deferred) is protected by _mutex.
  • dispatch() snapshots handlers under lock and invokes them out-of-lock to avoid deadlocks and reentrancy issues.

Logging:

  • Unusual or error conditions are reported via the provided debug::IDebug.

Flush and dispatch all deferred events.

The function pops events from the deferred queue and dispatches them one by one. It takes the minimal lock to pop an event and dispatches outside the lock to prevent handlers from blocking the queue or causing deadlocks.
