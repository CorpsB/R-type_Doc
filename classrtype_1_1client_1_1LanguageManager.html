Detailed Description

Singleton handling internationalization (i18n) and dynamic text translation.

The LanguageManager is responsible for:

  • Loading localized strings from JSON files.
  • Storing and mapping each translation key to multiple language codes.
  • Returning the appropriate localized text according to GameSettings::getLangTag().

Workflow:

  1. Call loadFile() to load a JSON translation file.
  2. Query translations using getTranslation(key).

If a key or translation is missing, fallback placeholders are returned.
