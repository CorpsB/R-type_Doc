Detailed Description

Raylib-backed implementation of the AudioDriver interface.

This class provides an operational audio driver that integrates with the Raylib sound system. It manages in-memory audio entries and controls playback through the AudioDriver interface used by the engine core.

Key features:

  • Safe concurrent access to the sound registry (_entries)
  • Adjustable master volume
  • Support for both file-based and in-memory sound loading
