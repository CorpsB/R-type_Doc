8/**
9 * @file Connection.hpp
10 * @brief Per-peer connection state (endpoint, sequencing, RTT, congestion window).
11 * @since 0.1
12 * @ingroup network
13 *
14 * @details
15 * Holds runtime metrics and identifiers for a single remote peer used by the
16 * networking layer (e.g., NetworkManager). It tracks:
17 * - The remote endpoint (address/port).
18 * - Send/receive sequence numbers for reliable traffic (channel 0).
19 * - A smoothed round-trip time (RTT) for retransmission timing.
20 * - A simple congestion window (cwnd) hint for future flow control.
21 *
22 * @note Sequence numbers are 32-bit unsigned counters. The send sequence
23 * typically starts at 1 and wraps after UINT32_MAX.
24 * @warning This type is not inherently thread-safe. Synchronize externally if
25 * accessed from multiple threads.
26 */
27

37/**
38 * @struct RemoteEndpoint
39 * @brief Simple transport-agnostic endpoint descriptor.
40 * @ingroup network
41 *
42 * @details
43 * Represents the network location of a peer. It is transport-agnostic from
44 * the perspective of higher layers (string address + 16-bit port).
45 *
46 * @var RemoteEndpoint::address
47 * Human-readable IP or hostname.
48 * @var RemoteEndpoint::port
49 * UDP/TCP port (0 means unset/invalid).
50 */
51struct RemoteEndpoint {
52 std::string address;
53 std::uint16_t port = 0;
54};

56/**
57 * @class Connection
58 * @brief Per-peer state used by the reliable layer and session management.
59 * @ingroup network
60 *
61 * @details
62 * Encapsulates:
63 * - Endpoint binding for this peer.
64 * - Send/receive sequencing for reliable messages (stop-and-wait in the
65 * current design).
66 * - Smoothed RTT in milliseconds (usable to derive RTO bounds).
67 * - Last receive tick (activity/keep-alive).
68 * - A basic congestion window hint `cwnd` (clamped by caller policy).
69 *
70 * Typical usage:
71 * - Call @ref bumpSendSeq when emitting a new reliable packet.
72 * - Call @ref noteRecvSeq on valid in-order reception to advance the receive
73 * window and update activity time.
74 * - Feed new RTT samples via @ref updateRtt when ACKs are observed.
75 */
76class Connection {
77 public:
78 /**
79 * @brief Construct a connection with default-initialized state.
80 * @since 0.1
81 *
82 * @details
83 * - Endpoint is empty (port 0).
84 * - Send sequence starts at 1.
85 * - Receive sequence starts at 0 (no packet received yet).
86 * - cwnd initialized to a conservative default (e.g., 32).
87 * - RTT is 0ms until the first update.
88 */
89 Connection();
