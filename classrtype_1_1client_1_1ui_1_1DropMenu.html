Detailed Description

Interactive UI component representing a collapsible dropdown menu.

The DropMenu class encapsulates a toggleable list of buttons that expands below a main button when activated. Each option can trigger a user-defined callback when selected.

It is ideal for small, custom GUI implementations where a lightweight dropdown mechanism is required.

Example usage:

using namespace rtype::client::ui;
DropMenu menu(100.0f, 100.0f, 200.0f, 40.0f, "Options");
menu.addOption("Start", [](){ startGame(); });
menu.addOption("Settings", [](){ openSettings(); });
menu.addOption("Quit", [](){ exit(0); });
while (!WindowShouldClose()) {
menu.update();
BeginDrawing();
ClearBackground(RAYWHITE);
menu.draw();
EndDrawing();
}
