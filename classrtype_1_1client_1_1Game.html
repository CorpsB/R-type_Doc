Detailed Description

Main client-side runtime class managing initialization, scenes, and the main loop.

The Game class serves as the root controller for the client. It is responsible for setting up Raylib, initializing audio and windowing systems, and managing the current active scene through the SceneManager singleton.

Example usage:

int main()
{
rtype::client::Game app;
app.startWith<MainMenuScene>();
app.run();
return 0;
}

void rtype::client::Game::run ( )

Executes the main game loop.

This function runs continuously while the window remains open. It performs the following operations every frame:

  • Computes delta time via Raylib’s GetFrameTime().
  • Updates the current scene through SceneManager::update().
  • Draws the scene via SceneManager::draw().

The loop continues until the user closes the window or the application is explicitly stopped.

Note
The background is cleared to RAYWHITE before each draw call.
Warning
Exiting the main loop will terminate the current game session.

template<typename TScene , typename... Args>
void rtype::client::Game::startWith ( Args &&...  args)
inline

Starts the game with a specific scene as the entry point.

This method creates and pushes a new scene of type TScene onto the SceneManager’s stack. The provided arguments are perfectly forwarded to the scene constructor.

It must be called before entering the main loop using run().
