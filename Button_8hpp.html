This file defines the rtype::client::ui::Button class — a minimal and interactive UI element rendered with Raylib. The class handles hover and click detection, dynamic rendering, and callback invocation for user interactions.

Responsibilities:

  • Manage button geometry, style, and label text.
  • Detect hover and click states through per-frame updates.
  • Execute user-defined callbacks upon interaction.
  • Render the button with custom colors, fonts, and radius settings.

The button is suitable for lightweight, immediate-mode GUIs such as those used in Raylib or similar frameworks.

Note
Label localization can be handled through LanguageManager.
Warning
The callback set via onClickAction must remain valid throughout the button’s lifetime.
