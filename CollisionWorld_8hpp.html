Detailed Description

Spatial-hash collision world API: grid building and narrow-phase tests.

Author
Jason KOENIG
Date
29/06/2025

Declares CollisionWorld, which implements a uniform grid (spatial hash) for broad-phase and an oriented-rectangle SAT-based narrow-phase test. Public API:

  • buildGrid(coord, entities)
  • clearGrid()
  • checkCollisions(coord)

Internals:

  • grid: unordered_map<cellKey, vector<entity_id>>
  • helper functions compute box corners, AABB, projection and axis separation tests.
