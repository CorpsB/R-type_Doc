Detailed Description

Implementation of spatial hashing helper utilities for 2D coordinates.

Version
1.0
Date
2025-03-26

Provides bitwise packing and unpacking functions for converting 2D integer coordinates into a 64-bit spatial lookup key and back.

This mechanism is typically used in spatial partitioning systems, such as grids or hash maps, where integer coordinates must be represented compactly as a single key for fast lookup.
