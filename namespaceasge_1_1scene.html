◆ asge::scene::SceneHandle

struct asge::scene::SceneHandle

Lightweight descriptor for a pushed scene instance.

SceneHandle represents metadata for a scene instance pushed onto the SceneManager stack. It is intentionally copyable and small so the manager can queue pending operations using it.

Members:

  • id: numeric id assigned by SceneManager (0 = invalid/unassigned).
  • type: textual type identifier used for diagnostics and factory lookups.
  • flags: SceneFlag bitset describing overlay/modal/persistence behaviour.
  • params: optional key/value parameters forwarded to scene init.

enum class asge::scene::SceneFlag : std::uint32_t
strong

Flags describing a scene instance behaviour.

The flags are used by SceneManager and SceneStage to control how a scene behaves in a stack. Typical usage:

  • Overlay: scene renders on top of the previous scene (previous remains visible).
  • Modal: blocks input to scenes underneath.
  • Persistent: the scene should not be automatically destroyed across some transitions.
Enumerator
None 

No special behaviour.

Overlay 

Renders above previous scene (previous remains visible).

Modal 

Blocks input to scenes below.

Persistent 

Not automatically destroyed by some transitions.

◆ SceneState

enum class asge::scene::SceneState : std::uint8_t
strong

Lifecycle state machine tracked by IScene/SceneStage/SceneManager.

Scenes transition through these states as they are created, initialized, entered, paused/resumed and finally destroyed. SceneManager uses this enum to decide which callbacks (onEnter/onExit) to invoke and to prevent double-init/double-destroy.

Enumerator

Initialized

Paused 

Scene is paused (another scene overlays it).

Exited 

onExit() was called (pending destruction or reuse).

Destroyed 

Final destructor state (object should be released).
