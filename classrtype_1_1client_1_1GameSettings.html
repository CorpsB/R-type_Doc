Detailed Description

Singleton managing global runtime and rendering configuration.

The GameSettings class centralizes client-wide parameters such as window size, scaling, language, and runtime activity. It ensures a consistent rendering experience across resolutions by maintaining proportional scaling relative to a base 16:9 aspect ratio.

Commonly used by UI elements and rendering subsystems to adapt their coordinates to the current viewport.

Example usage:

using namespace rtype::client;
auto &settings = GameSettings::getInstance();
settings.setScreenSize({1920, 1080});
settings.setLangTag("FR");
while (settings.getActive()) {
settings.syncWithWindow();
BeginDrawing();
ClearBackground(RAYWHITE);
// render stuff...
EndDrawing();
}

◆ syncWithWindow()

void rtype::client::GameSettings::syncWithWindow ( )

Synchronizes the scaling factor and viewport offset with the current render size.

  • Retrieves the current render width and height via Raylib.
  • Recomputes the scale factor relative to baseScreen.
  • Chooses the smaller ratio to maintain a consistent 16:9 aspect ratio.
  • Updates the viewport offset to center the rendered area when pillarboxed or letterboxed.

The function exits early if the window size remains unchanged since the last frame.

Note
This method should be called every frame or after resizing events.
