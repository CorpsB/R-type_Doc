Detailed Description

Singleton managing runtime settings and UI scaling for the R-Type client.

The GameSettings class centralizes the configuration and synchronization of rendering parameters, including screen dimensions, scale ratio, language tags, and global active state.

It ensures a uniform display experience by maintaining proportional scaling relative to a predefined 16:9 reference resolution.

This class also exposes helper methods to apply temporary settings (language, fullscreen, resolution) and synchronize internal states with the actual rendering window.

Example:

using namespace rtype::client;
auto &settings = GameSettings::getInstance();
settings.setScreenSize({1920, 1080});
settings.setLangTag("EN");
while (settings.getActive()) {
settings.syncWithWindow();
BeginDrawing();
ClearBackground(BLACK);
EndDrawing();
}

◆ syncWithWindow()

void rtype::client::GameSettings::syncWithWindow ( )

Synchronizes scaling and viewport offset with current render size.

  • Retrieves render dimensions from Raylib.
  • Recomputes scale relative to baseScreen.
  • Selects the smaller ratio to preserve a 16:9 layout.
  • Updates viewport offset for centered display when aspect ratios differ.

Skips computation if render dimensions remain unchanged.

Note
Should be called every frame or after window resize events.
