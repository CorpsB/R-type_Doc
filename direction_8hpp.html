Detailed Description

Declares directional data for movement-oriented entities.

Since
0.1

This header exposes a movement direction component expressed as a 2D vector. Systems typically combine the direction with a speed component to update the position of entities, and may normalize the vector using the provided helper.

struct asge::components::direction_attr_t

Component storing a 2D direction vector.

The vector is expected to be normalized before being used in physics or gameplay calculations. Systems can call normalize_direction to maintain a unit vector, preventing accumulation of floating-point errors.
