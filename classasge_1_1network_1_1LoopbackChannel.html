Detailed Description

In-memory echo implementation of NetworkChannel.

Emulates packet send/receive behavior locally without performing actual network I/O. This class is ideal for:

  • Unit testing serialization and packet handlers.
  • Verifying protocol logic without network overhead.
  • Running server/client logic in the same process.

Usage pattern:

asge::network::LoopbackChannel chan;
chan.openServer(9000);
chan.send({0x01, 0x02, 0x03});
chan.poll([](const std::vector<std::uint8_t>& data, const std::string&, std::uint16_t) {
});
