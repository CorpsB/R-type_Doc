Detailed Description

System that handles player input logic within the ECS.

PlayerSystem manipulates movement, firing, and score for entities representing players. It retrieves relevant components through the Coordinator and applies per-frame updates according to the input type.

Component requirements:

  • position_attr_t
  • direction_attr_t
  • speed_attr_t
  • score_attr_t
  • frequency_attr_t

Complexity: O(n) per call where n is the number of controlled player entities.

Parameters

The function updates the entity’s direction based on input and computes position deltas using speed and direction attributes. Missing components cause the entity to be skipped safely.
