Detailed Description

Base exception class for errors occurring in the R-Type engine.

This class stores both the location (where) and the reason (what) for the error. It is intended to be thrown when a fatal or unexpected situation occurs in the program. Unlike std::runtime_error, this class does not override what(), but provides accessor methods instead.
