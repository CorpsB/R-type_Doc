Detailed Description

Core class representing the R-Type game server.

This class encapsulates the initialization and runtime logic of the R-Type server. It manages the ECS coordinator responsible for entities and components, uses ServerClock to maintain a stable tick rate, and interprets the configuration provided through parser_args_t.

The main loop is handled by the run() method, which executes until _isEnd becomes true, typically when the server is instructed to shut down.

See also
rtype::ecs::Coordinator, ServerClock, parser_args_t
