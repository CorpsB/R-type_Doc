Detailed Description

ECS component representing the position of an entity in 2D space.

Since
1.0

This file defines the position_attr_t struct, which stores the X and Y coordinates of an entity in the game world. It is typically used by rendering, movement, and collision systems to determine where an entity is located.

struct position_attr_t

Component holding the 2D coordinates of an entity.

The x and y fields define the entity’s position on a 2D grid or coordinate system. These values may represent pixels, tiles, or world units depending on your engine logic.
