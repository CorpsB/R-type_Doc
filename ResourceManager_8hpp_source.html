11 * @since 1.0
12 * @ingroup client-core
13 * @see Texture2D, Font, Sound, GameSettings
14 *
15 * @details
16 * The **ResourceManager** class provides a centralized caching system for
17 * Raylib resources such as textures, fonts, and sounds. It ensures that
18 * assets are loaded only once and shared across the entire client, avoiding
19 * redundant resource allocation.
20 *
21 * Responsibilities:
22 * - Load and store assets using unique string keys.
23 * - Retrieve assets efficiently from internal maps.
24 * - Release all resources upon shutdown.
25 *
26 * The singleton pattern ensures global accessibility while maintaining
27 * strict lifetime control over Raylib resources.
28 */

38/**
39 * @class ResourceManager
40 * @brief Singleton class managing global asset loading and caching.
41 *
42 * @details
43 * The **ResourceManager** is responsible for handling all resource I/O operations,
44 * including loading, caching, and unloading textures, fonts, and sounds.
45 * It interfaces directly with Raylib’s resource API and stores data in internal
46 * hash maps for fast access.
47 *
48 * ### Features:
49 * - Prevents duplicate resource loading.
50 * - Provides efficient access through string-based lookup keys.
51 * - Handles automatic cleanup of Raylib resources at shutdown.
52 *
53 * ### Example usage:
54 * @code{.cpp}
55 * auto &res = ResourceManager::getInstance();
56 * res.loadTexture("player", "assets/player.png");
57 * Texture2D &player = res.getTexture("player");
58 * DrawTexture(player, 100, 100, WHITE);
59 * res.unloadAll();
60 * @endcode
61 *
62 * @note This class uses the Meyers Singleton pattern.
63 */
64class ResourceManager {
65 public:

67 * @brief Returns the global instance of the @ref ResourceManager.

71 * initialization and single-instance access.

73 * @return Reference to the singleton @ref ResourceManager.

124 * @throws rtype::exception::Error If loading fails.

127 void loadSound(const std::string &key, const std::string &path);

138 /**

145 * @post The resource caches are empty and all memory is released.

147 void unloadAll();
