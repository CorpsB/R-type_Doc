10/**
11 * @file IRenderer.hpp
12 * @brief Minimal high-level renderer interface (simple draw helpers).
13 * @since 0.1
14 * @ingroup renderer
15 *
16 * @details
17 * Interface publique minimale du moteur pour le rendu 2D haut-niveau.
18 * Elle définit un cycle de vie standard et quelques primitives essentielles :
19 * cercles, rectangles, sprites, et texte, ainsi que la mesure de texte et le
20 * chargement de textures via la couche de stockage.
21 *
22 * Cycle de vie attendu :
23 * @code
24 * renderer.init();
25 * while (running) {
26 * renderer.beginFrame();
27 * renderer.clear(0, 0, 0, 1);
28 * renderer.drawSomething();
29 * renderer.submitFrame();
30 * }
31 * renderer.shutdown();
32 * @endcode
33 *
34 * @note Sauf mention contraire dans une implémentation concrète, les appels
35 * sont supposés être effectués depuis le thread de rendu.
36 */
37

46 * @class IRenderer
47 * @brief Minimal public rendering interface for the engine/game.
48 * @ingroup renderer
49 *
50 * @details
51 * Contrat commun des backends de rendu. Fournit des opérations de cycle de vie
52 * (initialisation, frame begin/clear/present, redimensionnement, arrêt) et
53 * des helpers de dessin 2D. Les implémentations concrètes (ex. Raylib) doivent
54 * garantir qu'aucune méthode de dessin ne peut être appelée avant @ref init().
55 *
56 * Lifecycle: @ref init() -> [ @ref beginFrame(), @ref clear(), draw operations, @ref submitFrame() ]* -> @ref shutdown()
57 */
