Detailed Description

Minimal abstract timer interface.

Implementations must provide:

  • now() : current time as seconds (double)
  • deltaTime() : time elapsed since last tick (seconds)
  • sleep(sec) : sleeps/block for specified seconds (platform-dependent)
  • tick() : advance the internal timer state to compute new delta

Use ITimer polymorphically when the concrete timer behaviour needs to be injected (e.g. production vs test).
