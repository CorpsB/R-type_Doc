Detailed Description

Manages all plugins loaded at runtime.

This class abstracts the complexity of dynamic loading. It acts as the primary API to interact with plugins by providing uniform methods to load, retrieve, and unload them using unique identifiers.

The PluginManager uses PluginLoader internally to perform the actual system-level library handling. Each successfully loaded plugin is wrapped in a PluginHandle and stored in an internal registry.
