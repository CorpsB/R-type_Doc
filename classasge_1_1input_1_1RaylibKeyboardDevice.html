Detailed Description

InputDevice implementation using raylib keyboard & mouse APIs.

This device:

  • Queries Raylib each frame in poll() to capture key/mouse states.
  • Stores the result in an internal DeviceState snapshot.
  • Exposes the last snapshot via snapshot().
  • Can be temporarily disabled via setEnabled(), in which case poll() yields an empty/inactive state (no events).

The device is not copyable nor movable because it represents a concrete, process-wide hardware handle and retains a pointer to the engine debug service.

Note
Thread-safety: calls are expected from the main thread (same thread as Raylib). No internal locking is performed.

void asge::input::RaylibKeyboardDevice::poll ( )
overridevirtual

Polls Raylib and updates the internal snapshot.

Polls Raylib and refreshes the cached device state.

  • If enabled() is false, the snapshot is cleared and no input is recorded.
  • Translates native Raylib key codes to engine key codes through translateKey().
  • Also collects mouse buttons/wheel/position if the device supports it.
Exceptions
asge::error::Error(Recoverable) if a translation or backend read fails in a way that should be surfaced to the caller.
  • Clears previous key state containers before sampling.
  • Populates pressed/released/down sets for every interesting scan code.
  • Surfaces any unexpected backend failure through the debug service before rethrowing.
