Detailed Description

ECS system responsible for spawning entities during runtime.

The SpawnerSystem determines when and where entities such as enemies or projectiles are created within the ECS world.
It uses the provided random seed to ensure reproducibility of spawning patterns across sessions and consistent synchronization between the server and clients.

The update() method is expected to be called every tick from the server’s main loop.
