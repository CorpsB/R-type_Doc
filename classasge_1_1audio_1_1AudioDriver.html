Detailed Description

Abstract base class for audio drivers.

Provides the pure virtual interface for all audio driver backends. Implementations must override all functions to provide full functionality.

The driver operates at a low level: it deals directly with sound assets, playback handles, and master volume. Higher-level systems like AudioManager manage IDs, categories, and logic on top of this interface.
