Detailed Description

Concrete implementation of IRenderer using a Raylib-based RenderDriver.

Responsibilities:

  • Manage renderer lifecycle (initialization, frame submission, shutdown).
  • Bridge between engine systems and low-level rendering commands.
  • Handle basic 2D drawing: circles, rectangles, sprites, and text.

Limitations:

  • No deferred rendering or batching system (immediate dispatch).
  • No built-in camera or world transform management.
  • No thread safety.
