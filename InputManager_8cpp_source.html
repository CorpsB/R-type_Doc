10 * @brief Implementation of the @ref rtype::client::InputManager class.
11 * @since 1.0
12 * @ingroup client-core
13 * @see InputManager.hpp
14 *
15 * @details
16 * This file implements the behavior of the @ref InputManager, which provides
17 * a high-level abstraction for input handling via Raylib.
18 *
19 * The class associates human-readable action names (e.g., `"jump"`, `"shoot"`)
20 * with keyboard keys and offers per-frame queries for input events.
21 *
22 * Internally:
23 * - The @c _bindings map stores action → key associations.
24 * - Each query delegates to Raylib functions: @ref IsKeyPressed,
25 * @ref IsKeyDown, and @ref IsKeyReleased.
26 *
27 * This abstraction allows clean and flexible input remapping at runtime.
28 */
