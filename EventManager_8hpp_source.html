11/**
12 * @file EventManager.hpp
13 * @brief Concrete event manager implementing IEvent using a deferred queue.
14 *
15 * @details
16 * EventManager provides a thread-aware event bus with both immediate and deferred
17 * delivery modes. Deferred events are queued and processed on flush(). Subscriptions
18 * are keyed by string event type; handlers receive only the string payload.
19 *
20 * The implementation uses an atomic counter to allocate subscription ids and
21 * a single mutex to protect the registry and the deferred queue.
22 */

35/**
36 * @class EventManager
37 * @brief Thread-aware event bus implementation.
38 *
39 * @details
40 * Responsibilities:
41 * - `publish()` dispatches immediately to current subscribers.
42 * - `publishDeferred()` enqueues the event for later dispatch by `flush()`.
43 * - `subscribe()` returns a `uint64_t` id which is used to `unsubscribe()`.
44 *
45 * Thread-safety:
46 * - All public methods are safe to call concurrently.
47 * - Internal state (`_subs`, `_deferred`) is protected by `_mutex`.
48 * - `dispatch()` snapshots handlers under lock and invokes them out-of-lock
49 * to avoid deadlocks and reentrancy issues.
50 *
51 * Logging:
52 * - Unusual or error conditions are reported via the provided `debug::IDebug`.
53 */
