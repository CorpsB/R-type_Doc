11 * @since 1.0
12 * @ingroup server

14 * @details
15 * The `ServerClock` class provides a fixed-step timing mechanism designed for
16 * deterministic server-side updates in a real-time game loop.
17 * It ensures that systems update at a consistent rate (e.g. 60 ticks per second)
18 * regardless of CPU speed or frame variations.
19 *
20 * The class uses an internal worker thread, condition variables, and atomic flags
21 * to provide thread-safe timing control. It is typically used in the main server
22 * loop to synchronize ECS updates and network ticks.
