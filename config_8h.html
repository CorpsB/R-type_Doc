Detailed Description

Command-line and configuration file parsing for the R-Type server.

Since
0.1
See also
Parser.cpp

Public API for reading runtime options from argv and an optional .cfg file, validating them, and exposing the normalized result through parser_args_t. Flags can be applied twice (before and after loading the .cfg) so that command-line values override file values, as expected.

Warning
Thread-safety: the parsing API is not thread-safe; call it during startup.
Note
Default configuration file path is "Configs/DefaultServ.cfg".
