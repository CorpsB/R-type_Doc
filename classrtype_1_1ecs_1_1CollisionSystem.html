Detailed Description

High-level ECS system that delegates collision detection to a CollisionWorld.

CollisionSystem manages the timing and invocation of collision processing:

  • it uses _filtered_entities (populated by SystemManager) as the source entity set,
  • it calls CollisionWorld::clearGrid(), buildGrid(...), and checkCollisions(...)
  • collision responses are performed via CollisionWorld::collisionEffect(...)

This separation keeps the world-level spatial logic isolated from scheduling concerns.

Run one collision pass: rebuild spatial grid and test collisions.

Parameters
coordCoordinator reference to access components for entities.

Implementation steps:

  • _world.clearGrid()
  • _world.buildGrid(coord, _filtered_entities)
  • _world.checkCollisions(coord)

Each call recomputes the broad-phase grid from scratch for simplicity and correctness (suitable for many small/moving objects). If profiling shows rebuild is expensive, consider incremental updates.
