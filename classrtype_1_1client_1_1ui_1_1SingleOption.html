Detailed Description

Represents a single selectable menu option.

The SingleOption class handles both the visual representation and the logic of a menu box. It displays localized text, scales dynamically based on game settings, and executes a callback when selected and confirmed by the player.

The appearance of the option changes when it is selected to provide visual feedback.
