Detailed Description

Hash specialization for arcade::types::Position.

Enables the use of Position objects as keys in hash-based containers like std::unordered_map and std::unordered_set.

The hash function combines the hashes of the x and y coordinates using the Boost-style hash combining method to reduce collisions.
