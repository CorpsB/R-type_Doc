Detailed Description

Implements a spatial-hash broad-phase and SAT-based narrow-phase collision engine.

CollisionWorld maps world-space to discrete cells (cellKey from makeKey(cx,cy)). For each entity it:

  • computes oriented rectangle corners (fillBoxCorners),
  • converts corners to an AABB (cornersToAABB),
  • inserts the entity into all intersected cells, Then checkCollisions iterates cells and:
  • checks pairs within the same cell,
  • checks pairs across neighbor cells while avoiding duplicates using key ordering,
  • uses projection tests (projectOnAxis/isAxisSeparation) to determine overlap.
Note
  • Positions are interpreted using the project's fixed-point / scaling convention.
  • The collisionEffect method is a hook for application-specific response handling.

Build the spatial-hash grid from a set of entity ids.

Parameters
coordCoordinator to fetch components for each entity.
entitiesSet of entity ids to insert into the grid (typically system->_filtered_entities).

For each entity this function:

  • reads position_attr_t and hitbox_attr_t (skips entity if missing),
  • optionally reads direction_attr_t to orient the hitbox,
  • computes the four rotated box corners (fillBoxCorners),
  • converts corners to an AABB (cornersToAABB),
  • translates the AABB to cell coordinates via getCellsCount,
  • inserts the entity into each cell that intersects the AABB (insertEntityToCell).

The grid is a map from packed cell key to vector of entity ids.

Parameters
posIntPosition component (fixed-point integer units; implementation divides by 100).
hbIntHitbox component (width/height integers).
dirOptional direction vector (if nullptr the rectangle is axis-aligned).
outOutput array of four (x,y) float corner coordinates.
  • Interprets posInt.x/posInt.y as fixed-point (divides by 100.0 to get float world units).
