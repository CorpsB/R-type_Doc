Detailed Description

Interactive rectangular UI element for handling clicks and hover effects.

The Button class provides a minimal yet flexible implementation of an interactive button rendered using Raylib. It supports hover detection, pressed states, callbacks on click, and customizable styles via Button::Style.

Example usage:

using namespace rtype::client::ui;
Button btn(100, 100, 200, 60, "Play");
btn.onClickAction([]() { startGame(); });
while (!WindowShouldClose()) {
btn.update();
BeginDrawing();
ClearBackground(RAYWHITE);
btn.draw();
EndDrawing();
}
