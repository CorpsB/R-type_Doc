10/**
11 * @file RenderManager.hpp
12 * @brief High-level renderer service implementing the IRenderer interface using Raylib.
13 * @date 2025
14 * @ingroup renderer
15 *
16 * @details
17 * The RenderManager acts as a façade for all rendering operations in the engine.
18 * It owns or references a backend @ref RenderDriver, which performs actual GPU
19 * drawing via the Raylib library. The manager provides high-level convenience
20 * methods for 2D primitives, sprites, and text.
21 *
22 * It follows a minimal immediate-mode model:
23 * - The frame lifecycle is: @ref init() → [ @ref beginFrame(), @ref clear(),
24 * draw*, @ref submitFrame() ]* → @ref shutdown().
25 * - All draw calls are immediately forwarded to the driver.
26 * - Resource management (textures, fonts) is left to the driver or storage layer.
27 *
28 * @note This class is not thread-safe. All calls must occur on the render thread.
29 * @warning There is no multi-backend support in this version — only Raylib.
30 */
31

49 * @details
50 * Responsibilities:

53 * - Handle basic 2D drawing: circles, rectangles, sprites, and text.
54 *
55 * Limitations:
56 * - No deferred rendering or batching system (immediate dispatch).
