Detailed Description

Central coordinator that orchestrates entities, components and systems.

The Coordinator owns the three manager instances and exposes a compact API that game code and higher-level subsystems can use to interact with the ECS. It is intended to reduce boilerplate by forwarding template operations to the correct manager and triggering necessary bookkeeping (for instance: updating an entity signature and notifying systems when a component is added/removed).

EntityManager, ComponentManager, SystemManager
