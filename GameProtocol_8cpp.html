Detailed Description

Game-level packet (de)serialization helpers and conversion to game_event_t.

Small, explicit serializers and deserializers for game messages (create/move/destroy/input). All multi-byte numeric fields are encoded using network byte order where applicable. The functions return a contiguous byte buffer (serialize_*) or parse a buffer into typed payloads (try_deserialize_*). Deserializers validate buffer length before reads.

Convert a core packet event (protocol::packet_t inside core_event_t) into a game-level event.

Parameters
out_eventOutput game_event_t filled with the converted event.
coreCore event carrying a protocol::packet_t payload (PACKET_RECEIVED expected).
Returns
true always (conversion attempted). On malformed or unknown message_type, the function will set out_event.type to RAW_PACKET and place the original packet into the payload.
  • Examines the packet.header.message_type and tries to interpret payload bytes as a known game message (CREATE_ENTITY, MOVE_ENTITY, DESTROY_ENTITY, PLAYER_INPUT).
  • For recognized types, it calls the corresponding try_deserialize_* helper. If deserialization succeeds, the function sets out_event.type to the corresponding game_event_type_t and fills out_event.payload with the typed payload.
  • If deserialization fails or the message_type is unknown, out_event.type is set to RAW_PACKET and the original protocol::packet_t is moved into the payload for the consumer to examine.
Note
The function does NOT perform protocol-level validation beyond buffer-size checks done by the try_deserialize_* helpers. The caller should ensure core.payload holds a packet_t.
