Detailed Description

Minimal abstract interface for an event manager / event bus.

IEvent defines the contract used by subsystems to publish and subscribe to string-identified events. Handlers receive an opaque string payload.

Typical usage:

  • subscribe("PLAYER_HIT", handler) returns subscription id
  • publish({"PLAYER_HIT", "payload"})
  • publishDeferred(...) queues the event for later dispatch via flush()

Implementations are free to define the exact semantics of "deferred" publication.

virtual void asge::event::IEvent::flush ( )
pure virtual

Flush and dispatch all deferred events.

The function pops events from the deferred queue and dispatches them one by one. It takes the minimal lock to pop an event and dispatches outside the lock to prevent handlers from blocking the queue or causing deadlocks.
