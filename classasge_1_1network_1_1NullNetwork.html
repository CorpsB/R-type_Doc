Detailed Description

Dummy network backend performing no I/O operations.

Provides a minimal implementation of INetwork used for:

  • Continuous Integration (CI) and automated tests.
  • Headless server or simulation environments.
  • Safe fallback when no network backend is available.

All operations succeed or fail deterministically without accessing sockets. Internal state (_running) ensures consistent lifecycle semantics for testing.
