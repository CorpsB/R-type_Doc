Detailed Description

Declaration of the rtype::client::SceneManager class.

Since
1.0
See also
IScene

This file defines the rtype::client::SceneManager, which owns and manages the lifecycle of all game scenes. The manager maintains a stack-based structure where the scene at the back of the stack is always the active one.

Responsibilities:

  • Handle scene transitions (push, pop, replace) safely via deferred operations.
  • Maintain a stack of unique scenes, each implementing the IScene interface.
  • Provide lifecycle synchronization between scenes (enter, exit, pause, resume).

All modifications to the stack are deferred and processed in batch through flushTransitions() to ensure stability during updates.

Note
This class follows the singleton pattern.
Warning
Scene transitions should only occur between update cycles.
