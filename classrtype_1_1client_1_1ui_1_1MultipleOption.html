Detailed Description

Represents a menu option that contains multiple selectable sub-choices.

The MultipleOption class manages both the display and logic for an interactive menu box containing several possible choices. The user can navigate through these choices using the keyboard arrows, and each selection can trigger a corresponding callback function.

It adapts dynamically to the game’s scaling settings and renders localized text for both the main label and each available choice.
