Detailed Description

Declares the movement speed component.

Since
0.1

The speed component expresses how fast an entity should move when a direction or acceleration is applied. Systems interpret the unit (per second, per tick, etc.) based on the simulation model in use.

struct asge::components::speed_attr_t

Component describing the scalar speed of an entity.

The value is typically combined with direction or velocity components to compute displacement. It defaults to zero until explicitly set by gameplay.
