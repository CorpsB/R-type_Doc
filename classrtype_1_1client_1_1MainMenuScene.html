Detailed Description

Represents the primary interactive menu displayed at application startup.

The MainMenuScene serves as the central navigation hub of the R-Type client. It contains three main buttons—**Start**, Options, and **Quit**—each associated with a callback controlling scene transitions or application termination.

The layout is automatically centered and scaled using GameSettings, ensuring a consistent appearance across all screen resolutions.

Menu Options:

  • Start – Launches the gameplay sequence (currently placeholder).
  • Options – Switches to the OptionsMenuScene for configuration.
  • Quit – Exits the client gracefully.
Note
Uses ui::SingleOption for all menu items and ui::Sprite for the logo.
