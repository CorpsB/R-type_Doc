Detailed Description

Main entry scene displaying the game’s primary menu interface.

The MainMenuScene serves as the application’s primary navigation hub. It provides access to:

  • The game start sequence (placeholder or transition).
  • The options configuration scene.
  • The application exit routine.

Buttons are drawn using the ui::Button component and positioned dynamically based on the current screen size and scaling parameters.

Buttons:

  • Start – initiates the main gameplay or configuration sequence.
  • Options – transitions to OptionsMenuScene.
  • Quit – terminates the application via GameSettings.
Note
Layout and positioning automatically adapt to the screen resolution.
See also
OptionsMenuScene, ui::Button, SceneManager, GameSettings

rtype::client::MainMenuScene::MainMenuScene ( )

Constructs and initializes the main menu interface.

Constructs and initializes the main menu scene.

Creates three buttons with appropriate callbacks:

  • Start: placeholder for gameplay start.
  • Options: pushes the OptionsMenuScene.
  • Quit: exits the application via GameSettings.

Buttons are automatically sized and positioned relative to the base resolution.

Defines three buttons with specific actions:

  • Start ("001_START"): adjusts the resolution (placeholder for future gameplay launch).
  • Options ("002_OPTIONS"): replaces the active scene with OptionsMenuScene.
  • Quit ("003_QUIT"): deactivates the application through GameSettings.
Note
Button labels use localization keys (e.g., "001_START") resolved by the LanguageManager during rendering.
