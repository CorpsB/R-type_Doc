Detailed Description

Spawns entities from a map's spawn table as the player advances.

The constructor loads and sorts the map's spawn list by ascending distance. Each call to update() advances the spawn cursor, creating all spawns with distance <= current_progress. Calling spawnAll() forces creation of all remaining spawns in order. The reset() method resets the cursor and last progress, allowing the same map to be processed again (e.g., on reload).

void asge::script::LevelSpawner::spawnAll ( )

Synchronously spawns all remaining entries regardless of progress.

Immediately spawns all remaining entries in order.

Iterates the remaining spawn list from the current cursor and applies the same creation process as update(). This function is synchronous.

For each remaining spawn, this method:

  • parses optional position overrides from the spawn JSON,
  • retrieves the template handle by archetype,
  • creates the entity via EntityFactory::createFromTemplate,
  • notifies the network through EngineProtocol::sendEntityCreate.

Failures (unknown archetype, factory exception, invalid id) are logged as warnings and do not abort iteration. On completion, the cursor advances to the end of the spawn list.

void asge::script::LevelSpawner::update ( std::uint64_t  current_progress)

Progressively spawns entries whose distance has been reached.

Progressively spawns entries up to the given progress threshold.

Parameters
current_progressCurrent travel/progress value in the same unit as the map distances.

For every spawn whose distance <= current_progress, the spawner:

  1. Resolves an optional position override from the spawn JSON,
  2. Looks up the template (archetype) via the script manager,
  3. Creates the entity through EntityFactory,
  4. Notifies the network layer (EngineProtocol) of the new entity.

Unknown archetypes, factory failures, and exceptions are logged and skipped without aborting the loop. If current_progress goes backwards, the spawner will not respawn already-processed entries.

Parameters
current_progressProgress value used to unlock spawns (monotonic non-strict).

Spawns all entries where distance <= current_progress, starting at the current cursor. For each, it performs the same creation and notification sequence as spawnAll(). Unknown archetypes, exceptions, and invalid ids are logged as warnings. The cursor advances for every entry processed, and _last_progress is updated to the latest value (never forces respawn).
