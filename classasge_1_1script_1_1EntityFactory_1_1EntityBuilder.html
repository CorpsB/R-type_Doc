Detailed Description

Helper that assembles an entity based on optional component payloads.

The builder defers entity creation until build(). If an existing entity identifier is supplied to build(), components are added onto that entity instead of creating a new one. The builder logs warnings through the debug service when component insertion fails but does not throw.
