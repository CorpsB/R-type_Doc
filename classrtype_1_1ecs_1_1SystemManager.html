Detailed Description

Centralized registry for systems and their execution signatures.

SystemManager maps small integer type ids to System instances and keeps a corresponding execution signature (bitset of required components) for each registered system. When an entity's signature changes the manager updates every system's filtered entity set to add or remove the entity as appropriate.
