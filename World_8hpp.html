Detailed Description

ECS world managing entities, components, and systems in the engine.

Version
1.0
Date
2025-03-26

The World class provides the main interface for the ECS architecture:

  • Creates and destroys entities.
  • Registers and manages components.
  • Registers, enables, disables, and updates systems based on entity signatures.

It acts as a coordinator between EntityManager, ComponentManager, and SystemManager.
