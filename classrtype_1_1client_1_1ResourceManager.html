Detailed Description

Singleton responsible for loading, caching, and managing Raylib assets.

This class handles all texture, font, and sound resource operations in the client. Assets are cached in internal hash maps to prevent duplicate loading and improve performance. When shutting down, all resources are safely unloaded to free memory.

Example:

auto &res = ResourceManager::getInstance();
res.loadTexture("player", "assets/player.png");
Texture2D &player = res.getTexture("player");
DrawTexture(player, 100, 100, WHITE);
res.unloadAll();
