R-TYPE

R-Type is a C++ networked multiplayer game inspired by the original arcade classic. This project focuses on implementing a fully functional client-server architecture using modern C++ standards, Boost.Asio for asynchronous UDP networking, and Raylib for rendering. It is designed to be modular, scalable, and cross-platform, supporting both Linux and Windows environments.

Overview

This project implements a complete Entity-Component-System (ECS) architecture and a custom UDP-based protocol to ensure real-time, low-latency gameplay. The server handles game logic, synchronization, and communication between players, while the client provides an interactive, graphical interface using Raylib.

Technologies Used

  • Language: C++17
  • Build System: CMake
  • Dependency Manager: Conan
  • Networking: Boost.Asio
  • Graphics: Raylib
  • Testing: Criterion
  • Supported Platforms: Linux and Windows

Requirements

Ensure the following tools are installed:

  • Conan 2.x
  • CMake >= 3.23
  • A C++17 compatible compiler:
    • Linux: g++ (recommended)
    • Windows: MSVC (Visual Studio 2022 recommended)
  • Build tools:
    • Linux: make or Ninja
    • Windows: Visual Studio MSBuild or Ninja

Building the Project

Step 1: Install dependencies

Linux

conan profile detect
conan install . --output-folder=build --build=missing -c tools.system.package_manager:mode=install -c tools.system.package_manager:sudo=True

Windows

conan profile detect
conan install . --output-folder=build --build=missing

Step 2: Build

Linux

cmake --preset conan-release
cmake --build --preset conan-release

Windows

cmake --preset conan-default
cmake --build --preset conan-release

Step 3: Run

Linux

./build/Release/r-type_server
./build/Release/r-type_client

Windows

./build/Release/r-type_server.exe
./build/Release/r-type_client.exe

Server Usage

Usage: ./r-type_server [options]
The r-type_server executable launches our version of the R-TYPE game.
The game allows one or more players to face waves of enemy ships
that shoot at them. Compatible with both Windows and Linux.
Available options:
-h, --help Display this help message.
-d Enable debug mode.
-dd Show extended debug logs.
-ddd Show all debug logs.
-port=<number> Set the server port.
-ip=<address> Set the server IP address.
-path=<file> Specify the path to the configuration file.
Behavior notes:
• If no arguments are provided, the server will load the configuration from:
/Serv/Configs/Default.cfg
• Command-line flags always override the values specified in the configuration file.
Example:
./r-type_server -d -port=8080 -ip=192.168.1.10 -path=server.cfg
