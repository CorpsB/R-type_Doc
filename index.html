R‑Type Project – Multiplayer Shooter and Game Engine

Objectives

This repository contains both the Advanced Simple Game Engine (ASGE) and a networked side‑scrolling shooter inspired by R‑Type. The engine aims to provide a modular, cross‑platform framework for building games with C++20, while the game demonstrates how to use this engine to implement a real‑time client–server shooter with deterministic gameplay and custom networking. Dependencies

To build and run the project you will need:

  • CMake ≥3.20 – build system generator.
  • Conan 2.x – dependency manager that fetches third‑party libraries.
  • C++20 compiler – GCC 11+ or Clang 12+ on Linux; Visual Studio 2022 or newer on Windows.
  • Python 3.x – used by documentation tools (optional).
  • Git – to clone the repository and manage branches.

Third‑party libraries (Boost.Asio, raylib, nlohmann/json, etc.) are declared in the Conan recipe and will be downloaded automatically when running the build scripts.

Building the project

The repository provides helper scripts to automate the entire build process. These scripts run Conan to install dependencies, generate CMake presets and compile the targets.

Linux

From the repository root, run the following commands:

# Build and install the ASGE engine.
# This will compile the core engine, run all internal unit tests,
# and install the resulting shared/static libraries into the lib/ directory.
./lib/asge/tools/Linux/lib.sh all
# Build the R‑Type client and server.
# This script generates a CMake build directory, resolves Conan dependencies,
# and compiles both the server and client targets.
./rtype/tools/Linux/build.sh all
# Once compiled, you can verify the available runtime options for each binary:
./rtype/rtype-client -h
./rtype/rtype-server -h

The first script compiles the engine library and installs it into lib/, while the second script generates a build directory for the game, invokes CMake and copies the resulting binaries into the rtype/ directory. If you wish to produce a debug build, set CONFIG=Debug in the environment before running the scripts.

Windows

Open a Developer Command Prompt for your version of Visual Studio and execute:

REM build and install the ASGE engine
lib\asge\tools\Windows\lib.bat all
REM build the R‑Type client and server
rtype\tools\Windows\build.bat all
REM check available runtime options
rtype\rtype-client.exe -h
rtype\rtype-server.exe -h

As on Linux, you can set CONFIG=Debug to build debug binaries. The scripts create all necessary build folders and copy the executables (rtype-server.exe and rtype-client.exe) into the rtype/ directory.

Running the game

After a successful build, you can start the server and connect a client:

# start the server on the default port (9000)
./rtype/rtype-server 9000
# in another terminal, connect a client to the server
./rtype/rtype-client 127.0.0.1 9000

If the server is not yet running when the client starts, the client will retry until it succeeds. To connect to a remote server, replace 127.0.0.1 with the appropriate IP address. You can stop either program with Ctrl+C.

Documentation

Several Markdown documents in the doc/ directory complement the source code and Doxygen API reference:

  • **Developer Documentation (`doc/dev_doc.md`)** – explains the engine architecture, subsystems and ECS; provides build and extension tutorials; and outlines contribution guidelines.
  • **Network Protocol (`doc/network.md`)** – describes the binary UDP protocol used between clients and server, including packet structures, message types and reliability channels.
  • **Technical & Comparative Study (`doc/tec.md`)** – justifies the choice of technologies (C++, UDP, Boost.Asio, raylib) and compares them to alternatives; discusses algorithms, data structures, storage and security considerations.

Refer to these documents to better understand the engine internals, network implementation and design decisions.
