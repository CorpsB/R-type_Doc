Detailed Description

Represents a 2D textured sprite for UI rendering.

The Sprite class encapsulates the logic and rendering of a texture-based UI component. It stores both logical and scaled (“real”) position and size to adapt to the window scale dynamically.

See also
rtype::client::Resources::ResourceManager, rtype::client::Settings::GameSettings

Draws the sprite on the screen.

Fetches the texture from the ResourceManager and renders it using Raylib’s DrawTexturePro function. If the texture is invalid, an error message is printed in debug output.
