Detailed Description

Rich, categorized runtime error type for the engine.

Error instances are small, copyable exceptions that own their message and location strings. The what() message is lazily formatted and cached so that repeated calls are cheap. All accessor methods are noexcept and intended to be safe to call from destructors and logging code paths.
