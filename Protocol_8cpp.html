Detailed Description

Implementation of the core UDP protocol (sending/receiving, piggyback acknowledgment, ordered buffer).

This file contains the definitions of the methods of the protocol::Protocol class : socket initialization, IO loop (start_io/stop_io), packet sending (send_packet), management of reliable transmissions without an internal timer (process_pending / retransmit_sequence), and asynchronous reception with support for ordered delivery and ACK piggybacking.
