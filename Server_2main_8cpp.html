Detailed Description

Entry point for the R-Type server executable.

Since
0.1
See also
config.h, Rtype.hpp

Boots the server by parsing command-line flags, optionally loading a configuration file, re-applying flags so they override file values, then validating the final configuration before instantiating and running the server. Any runtime error derived from rtype::exception::Error is caught and reported with a non-zero exit code.

Warning
Thread-safety: initialization must occur single-threaded at startup.
Note
The default configuration file is "Configs/DefaultServ.cfg" unless a path is provided via -path or -path=<file>.

Program entry point.

Steps:

  1. Parse flags once to capture an optional -path for the config file.
  2. Load configuration key/values from the file if available.
  3. Re-apply flags so that CLI values override file values.
  4. Normalize and validate the final configuration.
  5. If requested, print help and exit; otherwise construct and run the server.
  6. Report any runtime error and exit with a failure code.
Parameters
acArgument count.
avArgument vector.
Returns
0 on success; 84 on invalid configuration or runtime error.
