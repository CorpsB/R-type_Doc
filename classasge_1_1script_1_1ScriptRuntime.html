Detailed Description

Abstract interface for script runtimes.

Implementations parse templates, convert payload strings into runtime values and resolve template inheritance by merging ScriptHandles. Concrete runtimes must ensure returned ScriptHandles are valid and throw or return std::nullopt on failure as appropriate.
