Detailed Description

Raylib-based implementation of the AudioDriver interface.

Since
0.1

The RaylibDriver provides a concrete implementation of the AudioDriver interface using the Raylib audio backend (or an equivalent audio engine). It handles:

  • initialization and shutdown of the audio backend,
  • a cache of sound/music entries identified by logical IDs,
  • playback control (play/stop/loop/pitch),
  • global master volume management.

Access to the internal entries map (_entries) is thread-safe via a mutex (_mtx) to ensure safe concurrent access between loading threads and the main thread.

The cache is limited by MAX_CACHE_SOUNDS to avoid excessive memory usage. High-level systems (like AudioManager) can decide when to unload unused entries.

Note
This driver is designed for client builds. For headless or server builds, use asge::audio::NullAudio instead.
