Detailed Description

Manages entity allocation, destruction and signatures.

The EntityManager maintains a dense vector of EntityData and a stack of free ids that can be reused. createEntity returns a new or recycled id (incrementing its generation). destroyEntity deactivates an entity and pushes its id back to the free list. Signatures can be read or set to reflect attached components.
