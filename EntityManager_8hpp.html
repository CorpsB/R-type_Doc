Detailed Description

Entity creation and lifecycle manager for the ECS.

Since
0.1
See also
ComponentManager.hpp, ComponentArray.hpp

EntityManager is responsible for allocating and recycling entity identifiers, tracking per-entity generation counters, activity flags and component signatures. It provides simple creation/destruction semantics and exposes signature accessors used by the system manager to match entities against system requirements.

Note
The implementation uses a free-list of entity ids and pre-allocates storage for MAX_ENTITIES (see Macro.hpp).
