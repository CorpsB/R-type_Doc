Detailed Description

Declaration of the rtype::client::LanguageManager singleton class.

Since
1.0
See also
GameSettings, rtype::exception::Error

The LanguageManager provides runtime localization support for the R-Type client. It loads and manages language files stored as JSON, enabling dynamic text translation based on the current language setting defined in GameSettings.

Each translation file defines a set of string identifiers mapped to language tags. The manager stores these translations in memory and provides access through getTranslation().

Example JSON format:

{
"001_START": { "EN": "Start", "FR": "Jouer" },
"002_OPTIONS": { "EN": "Options", "FR": "Options" }
}

Example usage:

auto &lang = LanguageManager::getInstance();
lang.loadFile("Assets/lang/lang.json");
std::string text = lang.getTranslation("001_START");
Note
Only one instance of this class exists in memory (Meyers Singleton).
