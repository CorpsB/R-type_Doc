Detailed Description

System that applies movement to entities based on speed and direction.

MovementSystem iterates _filtered_entities and updates each entity's position component according to:

  • position_attr_t (integer, fixed-point scale used by the project)
  • direction_attr_t (floating normalized dx,dy)
  • speed_attr_t (unsigned integral speed value)

The system performs a deterministic single-threaded update. Missing components for an entity cause that entity to be skipped for that update.

Complexity: O(n) per update where n is the number of matched entities.

Advance positions for all entities matched by the system.

Parameters
coordReference to the Coordinator so components can be retrieved.
ticksNumber of ticks to advance (default 1). Larger values scale movement linearly.

For each entity the function:

  • retrieves position_attr_t, direction_attr_t, speed_attr_t
  • computes a float delta according to speed and direction
  • rounds the delta and applies it to the integer position
Note
The update is immediate and destructive: it updates component values in place.
