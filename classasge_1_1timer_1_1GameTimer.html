Detailed Description

Game-facing timer: fixed-step, time-scale, pause control.

Fonctionnement :

  • lit le delta brut depuis _system (SystemTimer),
  • applique _timeScale pour produire un delta effectif pour la logique de jeu,
  • accumule ce delta dans _now (temps de jeu monotone),
  • expose un pas fixe configurable via _fixedStep.

Thread-safety :

  • Les lectures sont sûres, les mises à jour d’état sont protégées par _mutex.
  • _tickCount peut être lu sans verrou si nécessaire, mais l’accès reste sériel pendant tick() grâce au mutex.

Journalisation :

  • Les conditions atypiques (delta négatif inattendu, scale invalide, etc.) peuvent être signalées via _debugger.
