Detailed Description

Abstract base class for low-level communication channels.

Provides the minimal set of operations to manage a bidirectional packet-based transport channel. Implementations can differ in protocol and behavior, but all must adhere to the same lifecycle:

  1. Open (server/client)
  2. Configure (non-blocking, MTU)
  3. Send / Poll loop
  4. Close

Example usage:

std::unique_ptr<NetworkChannel> chan = std::make_unique<UDPChannel>();
chan->openClient("127.0.0.1", 4200);
chan->send({0x10, 0x20, 0x30});
chan->poll([](auto data, auto addr, auto port) { handle packet });
chan->close();
