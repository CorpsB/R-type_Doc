Detailed Description

Definition of audio_attr_t — component describing an entity’s sound state.

Author
Jason KOENIG
Date
29/06/2025

Declares the audio_attr_t component used by AudioSystem to control Raylib sound playback for entities. The component stores a key to a sound resource managed by ResourceManager and several flags representing playback state.

Responsibilities:

  • Identify which sound should be played via soundKey.
  • Control playback through boolean flags (play, loop, stop, playing).

This component is attached to entities that emit or control sounds within the ECS (e.g., background music, weapon effects, UI sounds, etc.).

struct audio_attr_t

ECS component that stores sound playback state and resource key.

The audio_attr_t component defines the minimal state required to control sound behavior for an entity. It is consumed by AudioSystem each frame to determine whether to start, stop, or loop a sound.

Members:

Field Type Description
soundKey std::string Key referencing a loaded Sound in ResourceManager
play bool Set true to trigger playback (reset after use)
loop bool Set true for continuous playback loop
stop bool Set true to immediately stop playback
playing bool True if the sound is currently active
Note
The component does not store a Raylib Sound object directly, only a lookup key to ensure centralized resource management.
