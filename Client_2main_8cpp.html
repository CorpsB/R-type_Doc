Detailed Description

Entry point of the R-Type client application.

Since
1.0
See also
rtype::client::Game, rtype::client::MainMenuScene, rtype::client::InputManager, rtype::client::LanguageManager

This file defines the main entry point of the R-Type client executable. It initializes essential managers (inputs, languages) and launches the game loop.

Initialization Steps:

  1. Binds standard input actions (arrows, enter, escape) using InputManager.
  2. Loads the translation file via LanguageManager.
  3. Starts the rtype::client::Game with the MainMenuScene.
  4. Enters the main game loop with Game::run().
Note
This function represents the starting point for the entire client runtime. The main menu scene is loaded first by design.

The main function performs the following:

  • Configures default key bindings for navigation and selection.
  • Loads the multilingual translation file for UI text.
  • Instantiates and launches the core rtype::client::Game instance.
