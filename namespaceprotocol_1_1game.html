Detailed Description

Game-level message IDs and payload definitions built on top of the core protocol.

The protocol::game namespace defines the application-level message identifiers and the wire payload layouts used by the game facade. These types map directly onto the low-level protocol::packet_header_t::message_type field and provide strongly-typed payload structures (create/move/destroy, player input, snapshots).

Use these types when encoding and decoding game messages; the game layer is responsible for packing the payload into a protocol::packet_t and setting the corresponding message_type value before sending.

struct protocol::game::game_event_t

Top-level game event exposed by GameProtocol.

Instances of this struct are produced by the GameProtocol facade and delivered to the application via is_event / wait_event. The type field describes the logical event kind and the payload variant carries the strongly-typed data for that event (or std::monostate when there is no payload).

◆ game_event_payload_t

using protocol::game::game_event_payload_t = typedef std::variant< std::monostate, payload_create_entity_t, payload_move_entity_t, payload_destroy_entity_t, payload_player_input_t, protocol::packet_t, protocol::transmit_failed_t, protocol::udp::endpoint >

Variant payload carried by a game-level event.

The variant holds one of:

  • std::monostate: no payload (NONE)
  • payload_create_entity_t: for CREATE_ENTITY events
  • payload_move_entity_t: for MOVE_ENTITY events
  • payload_destroy_entity_t: for DESTROY_ENTITY events
  • payload_player_input_t: for PLAYER_INPUT events
  • protocol::packet_t: for RAW_PACKET events (raw core packet)
  • protocol::transmit_failed_t: for TRANSMIT_FAILED events forwarded from core
  • protocol::udp::endpoint: for CONNECTED / DISCONNECTED events, carrying the peer endpoint
