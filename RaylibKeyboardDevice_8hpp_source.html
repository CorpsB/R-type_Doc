28/**
29 * @class RaylibKeyboardDevice
30 * @brief InputDevice implementation using raylib keyboard & mouse APIs.
31 *
32 * @details
33 * This device:
34 * - Queries Raylib each frame in @ref poll() to capture key/mouse states.
35 * - Stores the result in an internal @ref DeviceState snapshot.
36 * - Exposes the last snapshot via @ref snapshot().
37 * - Can be temporarily disabled via @ref setEnabled(), in which case
38 * @ref poll() yields an empty/inactive state (no events).
39 *
40 * The device is *not* copyable nor movable because it represents a concrete,
41 * process-wide hardware handle and retains a pointer to the engine debug service.
42 *
43 * @note Thread-safety: calls are expected from the main thread (same thread as Raylib).
44 * No internal locking is performed.
45 */
