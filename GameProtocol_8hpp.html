Detailed Description

High-level game protocol facade (header only).

Since
0.1 ::
See also
Core/Protocol.hpp, GameProtocolTypes.hpp

GameProtocol is a small singleton facade built on the low-level protocol::Protocol. It offers convenience functions to send the game-level messages declared in GameProtocolTypes.hpp and a polling API (is_event / wait_event) returning game-level events. The implementation (cpp) is responsible for packing payload structures into raw bytes and for translating core events into game_event_t instances.
