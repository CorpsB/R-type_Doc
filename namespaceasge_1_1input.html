enum class asge::input::KeyCode : int32_t
strong

Normalized key identifiers used across all input devices.

KeyCode is a unified enumeration for keyboard keys. Device-specific implementations (e.g., Raylib, GLFW, Win32) must translate their native scancodes into these normalized values.
