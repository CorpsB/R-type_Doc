Detailed Description

Declaration of the rtype::client::IScene interface.

Since
1.0
See also
SceneManager

This file defines the rtype::client::IScene interface, which serves as the base contract for all game scenes in the R-Type client. Each scene implements its own lifecycle behavior (enter, exit, pause, resume) and provides its own update and rendering logic.

Responsibilities:

  • Define a common interface for all scenes.
  • Provide consistent lifecycle management through SceneManager.
  • Enforce separation between update and draw logic.

Scenes are managed exclusively through the SceneManager using smart pointers to ensure proper ownership and cleanup.

Note
All derived scenes must implement update, draw, and name.
