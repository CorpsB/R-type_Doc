Detailed Description

Declares the entity creation and component registration helpers.

The EntityFactory module centralizes creation of all in-game entities (players, enemies, projectiles, etc.) using a shared ECS Coordinator. It exposes high-level functions that assemble the right set of components for each type of entity, while enforcing rollback on partial creation failure.
