Detailed Description

Main class responsible for communication between games and graphical libraries.

The Core class manages the main loop of the Arcade program. It handles dynamic loading, management, and runtime switching of games and graphical libraries. It also centralizes event handling, rendering, and error management during startup or execution.

See also
game::IGame, display::IDisplayModule
