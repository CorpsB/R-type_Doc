This file defines the rtype::client::OptionsMenuScene, a dedicated scene for managing and displaying configurable game options such as resolution, display mode, and language.

Responsibilities:

  • Render and manage multiple dropdown menus through ui::DropMenu.
  • Apply configuration updates immediately using GameSettings.
  • Ensure UI elements remain centered and scaled to the current resolution.

The scene is fully interactive and forms part of the in-game user interface system controlled by the SceneManager.

Note
This scene can be directly pushed or replaced in the SceneManager stack.
