Detailed Description

Declaration of the OptionsMenuScene class, handling the game’s settings menu.

The OptionsMenuScene class represents the in-game options menu, allowing players to modify runtime settings such as resolution, display mode, and language. It provides navigation through different configurable options using keyboard input and interfaces with GameSettings to store and apply changes.

This scene is part of the client’s scene management system and follows the IScene interface pattern.

Features:

  • Resolution selection (720p, 900p, 1080p)
  • Windowed/fullscreen toggle
  • Language selection (FR, EN, ZU)
  • Apply and Back actions
Note
The scene is fully navigable with arrow keys and Enter.

rtype::client::GameSettings, rtype::client::SceneManager
