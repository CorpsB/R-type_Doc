Detailed Description

Abstract interface implemented by user-defined scenes.

This interface defines the full lifecycle and behavior of a game scene. SceneStage is not an IScene; rather, it’s a higher-level construct managed by the SceneManager.

  • Each stage can represent a level, a menu, or a state of the application.
  • It defines how it reacts to lifecycle events and per-frame updates.
  • Background behavior is customizable through wants*WhenBackground() flags.
