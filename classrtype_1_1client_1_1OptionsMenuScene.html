Detailed Description

Scene representing the in-game options menu.

The OptionsMenuScene manages a collection of UI options for modifying graphical and language settings. It handles both rendering and user navigation logic, providing a seamless configuration interface.

The scene includes multiple selectable and editable options, implemented via IOption subclasses such as SingleOption and MultipleOption.

Navigation between options is handled with the UP and DOWN keys, and selections are confirmed with Enter.

See also
ui::SingleOption, ui::MultipleOption, GameSettings
