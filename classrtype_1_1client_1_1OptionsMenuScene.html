Detailed Description

Scene displaying configurable in-game options such as resolution, display mode, and language.

The OptionsMenuScene allows players to modify runtime settings using dropdown menus. Available categories include:

  • Screen resolution (720p, 900p, 1080p)
  • Display mode (windowed or fullscreen)
  • Language (FR, EN, ZU)

All dropdowns are powered by the ui::DropMenu class and automatically repositioned according to the current screen scaling.

Example usage:

using namespace rtype::client;
SceneManager manager;
manager.push(std::make_unique<OptionsMenuScene>());
while (gameIsRunning) {
manager.update(deltaTime);
manager.draw();
}
