Detailed Description

Implementation of the AudioManager.

This file contains the runtime logic of the audio management system:

  • Thread safety via scoped locking.
  • Communication with the low-level AudioDriver.
  • Lazy loading and cache eviction of audio entries.
  • Error translation into asge::error::Error with proper logging.

Public API details (parameters, returns, etc.) are already documented in AudioManager.hpp; only runtime behaviors specific to implementation are covered here.
