Detailed Description

Core implementation of the rtype::client::SceneManager class.

Since
1.0
See also
SceneManager.hpp, IScene

This file implements the scene management system responsible for handling scene transitions (push, pop, replace) through a deferred stack-based model.

Responsibilities:

  • Maintain a stack of active scenes.
  • Safely handle scene transitions between updates and draws.
  • Ensure lifecycle callbacks (IScene::onEnter, IScene::onExit, etc.) are properly executed during transitions.

Deferred operations prevent invalid state changes during active frame updates. Transitions are committed through flushTransitions() at controlled points in the frame loop.
