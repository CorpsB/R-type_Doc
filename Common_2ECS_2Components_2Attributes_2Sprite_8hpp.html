Detailed Description

ECS component representing the visual sprite of an entity.

Since
1.0

This file defines the sprite_attr_t struct, which identifies the sprite asset associated with an entity. The spriteTag serves as a key used by rendering systems to retrieve and display the correct texture or animation.

Typical usage includes associating entities with textures managed by rtype::client::ResourceManager or similar rendering utilities.

See also
rtype::client::ResourceManager, render_system

struct sprite_attr_t

Component linking an entity to its visual representation.

The spriteTag field holds an identifier string referencing a texture or sprite resource. This enables systems to look up the correct graphic to render for the entity on screen.
